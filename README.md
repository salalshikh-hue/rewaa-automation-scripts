# Rewaa QA & Training Automation Scripts

مجموعة سكريبتات Google Apps Script بُنيت لأتمتة مهام الجودة (QA) وربط جداول التدريب لفريق نجاح العملاء (CSM) والدعم الفني في رواء.

## المحتويات

### `qa-scripts/`
سكريبتات خاصة بنظام تقييم جودة CSM:

- **`QA_Slack_Alert.gs`** — يراقب شيت الجودة، ولو أي تقييم طلع أقل من 70%، يرسل تنبيه فوري لقناة سلاك مع تفاصيل نقاط الضعف بالتقييم.
- **`APPEND_TO_YOUR_SCRIPT.gs`** — نسخة معدّلة من تنبيه سلاك مصممة تُلصق داخل سكريبت لوحة أداء الجودة الموجود مسبقًا (بدون تعارض مع الدوال الحالية).
- **`QA_Automation.gs`** — يقرأ جدول جلسات CSM اليومي (قراءة فقط، بدون أي تعديل عليه)، يكتشف تلقائيًا آخر يوم مُضاف، يستخرج الجلسات، يصنفها حسب نوع المعيار (Chat/Case Handling/Activation/Reactivation)، ويبني جدول مراجعة جودة تلقائي في ملف منفصل.

### `geidea-matching/`
- **`Match_TRSM.gs`** — يقارن أرقام TRSM بين صفحتين بنفس الملف (بيانات التدريب مقابل قائمة NearPay المرجعية)، ويلوّن كل صف أخضر (موجود) أو أحمر (غير موجود) تلقائيًا.

## طريقة الاستخدام

كل سكريبت مستقل، وفيه تعليمات التركيب والإعداد مكتوبة بالتفصيل كتعليق بأول الملف نفسه (بالعربي). الخطوات العامة:

1. افتح ملف Google Sheet المستهدف.
2. من القائمة: `Extensions > Apps Script`.
3. الصق محتوى السكريبت المطلوب.
4. عدّل قيم الإعدادات بأعلى كل ملف (أسماء الشيتات، الروابط، إلخ) حسب حالتك.
5. شغّل دالة الاختبار (`testDryRun` أو ما يعادلها) للتأكد قبل التفعيل الكامل.

## ملاحظة

هذي السكريبتات مبنية خصيصًا لهيكلة بيانات معينة (أسماء أعمدة، تنسيق تواريخ) — لو تغيّر شكل الشيت المصدر، قد تحتاج تعديل بسيط بمنطق القراءة.
